# GitHub のコードレビューに対応する手順書

1. 現在の Branch に対応する Pull Request が存在するか確認する。
  - Pull Request が存在しない場合は、何もせずに終了する。
2. Pull Request のレビューコメントのうち、Resolve されていないレビューコメントを全て取得する。
  - Resolve されていないコメントがない場合は、何もせずに終了する。
  - コメント対象のコードの行番号ではなく範囲を正確に取得する。必要があれば、ページングを行い、全てのコメントを取得する。
3. 各々の GitHub のコードレビューのコメントを確認し、妥当な内容であるかを判断する。
4. 妥当な指摘であれば、コードを修正する。
5. 全てのコードレビューのコメントに対して、コメント返信を行う。
  - 修正した場合は、修正内容をコメントする。
  - 修正しなかった場合は、修正しなかった理由をコメントする。
6. コメント返信した後、レビューコメントを Resolve する。
